# Flask STOCK-ALGO-DASHBOARD API

## Overview

This project is a React-based application that uses a Flask API as the backend to fetch data from DynamoDB.

## Features

-   Fetch data via API endpoints.
-   Structured to allow for easy addition of new routes and functionality.
-   Uses React, a lightweight and flexible front-end framework.

## Prerequisites

Ensure that you have Node.js and npm (Node Package Manager) installed on your system. You can verify the installation by running the following commands:

```bash
node -v
npm -v
```

If Node.js and npm are not installed, download and install them from [Node.js official website](https://nodejs.org/).

## Setup

### 1. Install Dependencies

Next, install all the necessary dependencies for the project by running:

```bash
npm install
```

This command will install all the packages listed in the `package.json` file, including Tailwind CSS and other required libraries.

### 2. Run the Application

Once the dependencies are installed and Tailwind CSS is set up, you can start the development server with the following command:

```bash
npm run dev
```

This will start the development server, and you can view the application in your browser at `http://localhost:5173`.

### 3. Building for Production

To build the application for production, run:

```bash
npm run build
```
